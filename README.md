# CCI-SIO26-Portfolio-CastagneMathieu

Portfolio de Mathieu Castagné, étudiant en BTS Services informatiques aux organisations (SIO), option Solutions d’infrastructure, systèmes et réseaux (SISR), en alternance à CCI Campus Strasbourg.

Ce site présente mon parcours, mes projets et ma veille technologique à de futurs employeurs comme au jury du BTS. Il est réalisé dans le cadre de l’atelier de professionnalisation 1 (AP1).

## Contenu du dépôt

- `documentation` : le dossier d’étude du projet
  - `contenu.md` : textes et illustrations du site
  - `charte.md` : charte graphique, maquettes et logique de navigation
  - `technique.md` : technologies utilisées et environnement de développement
  - `medias` : images utilisées dans ces documents
- `html` : le site lui-même, en HTML, CSS et JavaScript

## Technologies

Site statique en HTML5, CSS3 et JavaScript natif, sans framework. Développé dans une machine virtuelle Ubuntu Server créée avec Multipass et servi par Apache. Le détail de l’environnement et la procédure pour le reconstruire se trouvent dans `documentation/technique.md`.
